# 全般
プロジェクト全般にかかわる共通の規約を記載します。

*各言語に関する規約は専用のファイルで管理します。
HTML/CSS：[Google HTML/CSS Style Guide](https://google.github.io/styleguide/htmlcssguide.html) を翻訳して再編
JavaScript：[Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript)のREADMEをそのまま採用

* 関数には原則、内容を簡潔に表した説明のコメントを付けてください。
* 文字列リテラルはシングルクォーテーションで括ってください。文字列中にシングルクオーテーションを含む場合に限りダブルクオーテーションを使用しても構いません。
〇: 'hogehoge'
×: "hogehoge"
* インデントはスペースではなく、タブにしてください。

# オセロゲーム仕様書

## 1. 概要
このドキュメントは、ブラウザベースのオセロゲームの仕様を定義します。プレイヤー VS CPUで対戦します。
難易度や先攻/後攻を選択することができます。

## 2. ゲーム設定

### 2.1 難易度設定

| 難易度 | 説明 | 評価基準 |
|--------|------|----------|
| Easy（初級者向け） | CPUの手の選択が完全にランダム | 有効な手の中から無作為に1つを選択 |
| Normal（中級者向け） | 基本的な戦略を実装 | 石を裏返せる数 + 1 をスコアとして使用<br>最も多くの石を裏返せる手を選択 |
| Hard（上級者向け） | 高度な戦略を実装 | 基本スコア：石を裏返せる数 + 1<br>角を取れる場合：+10点のボーナス<br>端を取れる場合：+5点のボーナス |

### 2.2 プレイヤー設定
- 先攻（黒）を選択可能
- 後攻（白）を選択可能
- ランダム（先攻/後攻がランダムに決定）

## 3. ゲーム機能

### 3.1 基本機能
- 8x8のゲームボード
- 有効な手のプレビュー表示
- 石を置いた時の回転アニメーション効果
- パス時のポップアップ通知
- 新しいゲーム開始機能

### 3.2 ゲーム進行
- 初期配置：中央4マスに黒白交互に配置
- 交互に手番を進行
- 有効な手がない場合はパス
- 両者ともパスの場合、ゲーム終了

### 3.3 スコア管理
- プレイヤーとCPUの石の数をリアルタイム表示
- ゲーム終了時の勝敗判定（黒と白の石の数を比較）

### 3.4 追加機能
- デバッグモード切り替え機能（CPUの手をプレイヤーが打てるモード）
- 1手戻る機能（デバッグモード時のみ利用可能）

## 4. UI/UX仕様

### 4.1 画面構成
1. タイトル画面
2. 難易度選択画面
3. 先攻/後攻選択画面
4. ゲーム画面

### 4.2 アニメーション
- 石を置く際の回転アニメーション
- パス時のフェードイン/アウトアニメーション（2秒間）
